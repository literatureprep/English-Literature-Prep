# LitPrep V2 — English Literature Exam Hub

## Included
- 220+ searchable topic modules
- 60+ author/critic profiles
- Literary chronology/timeline
- 120 practice MCQs
- 20-question timed mock-test engine
- Browser-local bookmarks
- Global search across topics and authors
- Responsive mobile/desktop design
- No external libraries and no paid services required

## Important note about PYQs
The PYQ section is a tracker/workspace. It intentionally does NOT label invented or generic questions as authentic previous-year questions. Add verified PYQs from official/authorized exam sources as you expand the site.

## Run
Open `index.html` in a browser.

## Free GitHub Pages publishing
1. Create a GitHub account.
2. Create a public repository, e.g. `litprep`.
3. Upload `index.html`, `style.css`, `data.js`, `script.js`, and `README.md`.
4. Repository Settings → Pages.
5. Source: Deploy from a branch → `main` → `/ (root)` → Save.
6. Open the GitHub Pages address shown there.
